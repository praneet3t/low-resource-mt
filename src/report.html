Machine Translation with Pretrained Models

Abstract. We compare zero-shot translation with one epoch of QLoRA adaptation for MADLAD-400 3B and Gemma 3 1B on English↔Khasi and English↔Bodo. MADLAD improves in both BLEU and chrF++ across all four directions. Gemma shows mixed gains. Its English→Bodo outputs increasingly use Devanagari, but also repeat more often and require substantially more edits.

1. Introduction and dataset

We ask how the two pretrained models respond to the same low-resource supervision, and whether improvements in corpus scores coincide with better translation behavior. The WMT26 Indic translation task places Khasi and Bodo in different resource categories [1]. Using both directions for each language lets us examine whether adaptation helps when generating the lower-resource language as well as when translating into English.

2. Experimental methodology

After seed-42 shuffling, we screened for exact matches between normalized parallel sides and official inputs, then removed later pairs that repeated a previously kept side. Each language contributed equal-sized validation and test splits, each capped at 1,000 pairs. Both directions of each pair stayed in the same split, yielding $train_count directed training examples per model.

MADLAD [2] prepends <2en>, <2kha> or <2brx> to the source. Its decoder attends to encoder states and consumes shifted target tokens in training. Gemma [3] receives a chat-templated instruction to translate between the named languages and return only the translation, followed by the source. Its target follows the prompt in the causal sequence. Instruction and source labels are masked.

4. Error analysis and conclusion

For Gemma into Bodo, outputs flagged for the wrong majority script fell ($wrong_script out of $bodo_n), while repeated-trigram flags rose ($repetition). The chrF++ increase ($bodo_chrf) coincided with a much higher TER ($bodo_ter). An output can acquire the expected script and match more reference fragments while repeating enough material to require many more edits.

Limitations and conclusion

The labeled sentences come from the same corpus as training, with one reference per source. Near duplicates and pretraining overlap were unmeasured. One seed, two languages and the absence of bilingual adequacy judgments limit generalization. MADLAD improved consistently under this setup. The mixed Gemma outcomes show why script checks, repetition diagnostics, edit rate and example inspection matter alongside overlap scores.
